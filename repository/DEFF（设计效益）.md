# DEFF（设计效应）

> **一句话**：DEFF（Design Effect，设计效应）衡量"样本不独立"对统计推断的影响，
> 把名义样本量 n 折算成有效样本量 $n_{\text{eff}} = n / D$。
> D = 1 表示样本独立；D > 1 表示有效信息比表面样本量少。

## 1. 背景：为什么需要它

经典统计公式（标准误、置信区间、检验功效）大多假设样本**独立同分布**。
但现实数据常有正相关性：同一单元相邻的观测相似（时间自相关）、
同一个体贡献多次测量（聚类/分层抽样）。
把相关样本当独立样本用，会**高估有效信息量**，导致标准误偏小、置信区间过窄、p 值过小，
结论过于乐观。

Kish（1965）提出设计效应来量化这一损失：

$$D = \frac{\mathrm{Var}(\hat{\theta}_{\text{实际设计}})}{\mathrm{Var}(\hat{\theta}_{\text{同样本量的简单随机抽样}})}$$

即"当前抽样/数据设计下估计量的方差"与"独立样本假设下的方差"之比。

## 2. 常见形式

### 2.1 聚类（群内相关 ICC）

按群（学校、家庭、批次）抽样的调查中：

$$D = 1 + (m - 1)\,\rho_{ICC}$$

- m：平均每群样本量；
- $\rho_{ICC}$：组内相关系数（同一群内两观测的相关性）。

群越大、ICC 越高，DEFF 越大。这是抽样调查（如 DHS、投票民调）中的标准修正。

### 2.2 时间自相关（自回归序列）

对时间序列 $Y_1, \dots, Y_n$（如二值事件序列、逐窗指标），自相关修正为：

$$D_{std}(L) = 1 + 2\sum_{k=1}^{L-1}\left(1 - \frac{k}{L}\right)\rho_k$$

- $\rho_k$：lag-k 自相关系数；
- L 是截断长度（只累计相关显著的 lag 范围）；
- 计算结果下限截到 1.0（负自相关最多使 D 趋近 1，不小于 1）。

这是项目里 [[口径与术语]] 采用的形式（L=10）。

### 2.3 加权（Kish 公式）

不等概率加权抽样中：

$$D_{Kish} = \frac{n \sum w_i^2}{\left(\sum w_i\right)^2}$$

权重越不均匀，D 越大。

## 3. 用法与注意事项

1. **折算有效样本量**：$n_{\text{eff}} = n / D$，再代入常规公式（如 Wilson 区间、t 检验）。
2. **D 只应≥1 用于保守化**：实测 D 低于假定值时，通常仍取 $\max(D_{assume},\ D_{obs})$，
   不能因实测低就宣称"更精确"。
3. **零方差序列不可估**：全部相同值（如全 0）的自相关无定义——
   此时 DEFF 是**不可估**，既不是 D=0，也不应默认 D=1；
   只能采用事先假定的常数，并在结论中带上相应定语。
4. **估计窗口要匹配数据生成机制**：若序列被某种干预切成块
   （如不同实验条件的分段），在整段上估自相关测到的是"干预的块结构"，
   不是时间相关性；应在同条件子序列内估计。
5. **不同指标不要混用**：连续型观测的 DEFF 与二值事件序列的 DEFF 描述的是不同对象的
   相关结构，用途要分开。
