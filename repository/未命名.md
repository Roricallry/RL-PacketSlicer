| 维度     | Contextual Bandit                      | 强化学习 RL                         |     |
| ------ | -------------------------------------- | ------------------------------- | --- |
| 决策长度   | 每轮只做一次决策，做完就结束                         | 多步序列决策，动作影响后续                   |     |
| 状态/上下文 | 有上下文 xx，但动作不改变未来上下文                    | 有状态 ss，动作会改变下一状态 s′s′           |     |
| 状态转移   | 没有状态转移，或下一轮上下文与动作无关                    | 有转移 (P(s's,a))                  |     |
| 目标     | 最大化即时奖励期望                              | 最大化长期累积折扣回报 E[∑γtrt]E[∑γtrt​]   |     |
| 动作影响   | 只影响当前奖励                                | 影响未来状态、未来奖励和后续数据分布              |     |
| 信用分配   | 奖励直接对应刚选的动作                            | 奖励可能延迟，需要判断哪些动作贡献了回报            |     |
| 数据分布   | 每轮上下文通常独立同分布                           | 轨迹数据由策略生成，非独立同分布                |     |
| 探索     | 探索只影响当前收益和估计                           | 探索会改变未来轨迹，可能发现新状态               |     |
| 典型算法   | LinUCB、Thompson Sampling、ε-greedy、EXP4 | Q-learning、DQN、PPO、A3C、SAC、策略梯度 |     |
| 离线评估   | IPS、Doubly Robust 等                    | OPE，更复杂，因为策略影响状态分布              |     |
