# 口径与术语

四个实验共用的一套定义。**先读这页，再看各实验页**，否则数字会对不上。

---

## 1. 变量

| 符号 | 含义 | 谁决定 |
|---|---|---|
| **U** | 链路负载水平（%），由 139 节点的 iperf3 施加 | 实验者设定，是**环境条件**，不是策略输出 |
| **P** | 每个 TLS 数据包被**分割**的概率，动作空间 21 档 `{0, 0.05, …, 1.00}` | 控制器/实验序列 |
| **ΔR** | 分割后包长分布的信息熵增益（bit），是**奖励口径** | 由 P 与包长分布决定 |
| **越限** | `1{ tls_constraint > 100.0 ms }` | 冻结阈值，四个实验都不调整 |
| **越限率 p** | 越限窗口数 / 可用窗口数 | — |

> ⚠ **奖励里没有时延。** `W=1` 使 reward ≡ ΔR；时延只通过二值约束代价进入。
> 约束是**违例率**约束，不是平均时延约束。

## 2. 测量量

### TLS 时延（`tls_constraint`）

- 在 `br-lan` 上**被动抓包**，把出站段的 `seq+len` 与回来的 ACK 配对，
  RTT = 两个抓包时间戳之差。
- **它是 TCP ACK RTT，不是应用层端到端时延。** 受延迟确认、重传、合并 ACK 影响；
  单条样本有 ±13–20 ms 量级的噪声。簇间/格间的**漂移**可以是真的（已被 ICMP 独立证实），
  **单条单窗的差**不能当结论。
- 报出的是 **1.5×IQR 剔除后的均值**（`rtt_avg_ms`）；取"第一个有样本的 IP"。
- 可能为 `NaN`。**缺失 ≠ 未越限**：任何分析里缺失窗都从 `n` 里扣掉，不能算作安全窗。

### ICMP 时延（`icmp_mean`）

- 主动 ping（目标 `192.168.2.5`），每窗 30 个样本，1.5×IQR 剔除后取均值。
- 与 TLS 打的是**两台不同设备**（ICMP 打网关侧 `.5`，TLS 打智能插座 `.221`/`.224`）。
  两者的一致性只能说明**网络层同时变化**，不能把绝对值互相当替代。

### `raw_packet_count`

- `Σ_ip len(per_ip[ip].raw.rtts)`，即该窗**成功配对的 TCP 段数**，典型值 ≈20。
- `anomaly_flag = 1 if raw_packet_count < 10`（G1 冻结口径）。
- 它跟**拥塞 U** 走，**不跟 P 走**；它是"手机点击器还在不在发包"的判据，
  不是 P 的生效证据。
- `raw_packet_count` 低 ≠ 点击器停摆（见 [[阶段 4B 安全可行区验证]] 的 §3.2）。

### 窗 / 时段 / 簇 / 格

| 词 | 含义 | 典型长度 |
|---|---|---|
| **窗** | 一次测量单元：settle → 4 探针并行 → 间隔 | 30 s + 1–2.5 s |
| **session / 时段** | 一次连续采集（G3 叫"簇"） | 4A 185 窗 ≈1.68 h；PW 180 窗 ≈1.64 h；4B 555 窗 ≈5 h |
| **格** | 一个固定 (U, P) 条件 | G3 100 条 ≈52 min |
| **簇（G3）** | 一次四格扫描 | ≈3.5 h |

## 3. §9 冻结判定（4A / 4B 共用）

```
n      = 可用窗数（tls_constraint 为有限数；缺失不计入、也不当作未越限）
D_use  = max(2.707, DEFF_obs)
n_eff  = n / D_use
p̂      = k / n
hi     = Wilson(p̂, n_eff)          # 单侧 95%，z = 1.645
```

**判定顺序（先到先判，不许跳过）：**

| 条件 | 结论 |
|---|---|
| `n < 360` | **尚无法完成**（条件性筛选） |
| `k/n ≥ 2%` | **点估计未达标** |
| `hi < 2%` | **在假设 DEFF ≤ 2.707 的条件下通过筛选** |
| 其他 | **尚无法认证** |

**几个关键数（D_use = 2.707、z = 1.645）：**

| 情形 | 单侧上界 |
|---|---|
| k=0, n=370（n_eff=136.68） | **1.941%** |
| k=0, n=360（n_eff=133.0） | 1.994% |
| k=1, n=370 | 2.442% |
| k=2, n=370 | 2.903% |
| U90（4A，k=269）：无参考意义 | 78.48%（已先判点估计） |

⇒ **在 360–370 窗的预算下，只有零越限才可能通过 A 层。**
U50/U60 的 1.941% 距 2% 只有 **0.059 个百分点**，是"刚好过线"，不是"远低于"。

**Wilson 口径的修正**（Round 26）：观测比例用真实 `n` 算，区间放在 `n_eff` 上；
等价于 `k_eff = p̂ · n_eff`。旧写法把原始 `k` 直接代进 `n_eff`，在 k > n_eff 时给出无意义值。

## 4. DEFF（设计效应）

- `DEFF_std(L=10) = 1 + 2 Σ_{k=1}^{9} (1 − k/10) ρ_k`，下限截到 1.0。
- 逐时段估 `ρ_k` → **跨时段取中位**（不池化）。
- `D_assume = 2.707` 是**事先假定的过程常数**，不是实测上界。
- **恒零序列不可估**（U50/U60 的 P=0 档就是这种情形）：它们的通过**完全依赖这个假设**。
- 4B 的 DEFF 必须在**同一 P 的子序列**上算：整段指示量被 P 自身的大效应切开，
  在整段上估自相关测到的是"P 的块结构"，不是时间相关性。
- **估得低于 2.707 不构成认证**；一律记「尚无法认证」。

## 5. 跨批次不可比

同名 (U,P) 在不同批次之间的绝对水平可以差很多：

| 对照 | PW（S1–S5） | 4A |
|---|---|---|
| U=90, P=0 越限率 | **84.33%** | **72.70%** |
| U=90, P=0 TLS 中位 | **130.93 ms** | **117.89 ms** |

差 **11.6 pp**。所以：

- **不能拿 4A 的 P=0 顶替 4B 的 P=0**（4B 必须现场重采）；
- **不能拿 G3 的旧安全表判断当前环境**；
- 颜色/批次是**身份**，不是可加权的分组。

## 6. 证据分级

每一条结论前都标一档：

| 标记 | 含义 |
|---|---|
| **[实测]** | 直接由落盘数据算出，口径事先冻结 |
| **[推论]** | 由实测推得，但带明确假设（假设要写出来） |
| **[观察]** | 描述性事实，未做正式检验，不能当结论 |
| **[未答]** | 当前数据回答不了；**不等于**现实中不存在 |
| **[设计意图]** | 事先选定的设计理由，不是数据结论 |

另有两条措辞纪律：

1. **"尚无法认证" ≠ "不安全"。** 上界没过线只说明样本量不足以排除 2%，不说明真实风险高。
2. **"当前数据未检测到" ≠ "不存在"。** 缺的是功效/设计，不是证据的否定。

## 7. 采集红线（与笔记相关的操作事实）

- **停采集只按 Ctrl-C（SIGINT）。** `pw_collecting.py` / `g3_collecting.py` 没有 SIGTERM 处理器；
  硬杀会跳过 `finally`，139 节点上的 iperf3 带着最后挡位一直跑，污染之后所有测量。
- **`pw_collecting.py` 是冻结文件**（sha256 `0308288…47b56`），四个阶段都用同一个采集器。
- **身份闸门**：每个新 outdir 要人工确认 TLS/ICMP 目标身份；出现未确认的新目标立即停。
- **跨批次同名条件的绝对水平不可比**（见 §5）。
